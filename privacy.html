01本机数据

本政策说明通勤小记 App，以及用于支持和隐私说明的静态网站如何处理数据。App 无需注册独立账号，主要功能可离线使用。

通勤日期和状态、单日费用、月度费用设置及工作日偏好先保存在设备的本地数据库中。提醒设置、引导完成状态和同步诊断等状态也保存在设备中。iPhone App 与小组件通过 Apple App Group 共享数据库。

02可选 iCloud 同步

开启同步后，App 会将通勤记录、费用设置、工作日偏好，以及同步所需的技术元数据传输到 Apple CloudKit 中属于你 Apple 账户的私有数据库。元数据包括记录标识、设备操作标识、变更标识和更新时间；App 也在本机保留用于区分 iCloud 账户的数据范围标识。

开发者无法通过 CloudKit 开发者控制台查看该私有数据库。Apple 根据其服务条款和隐私政策处理 iCloud 数据；同步是否可用取决于账户、网络和储存空间等条件。同步不是使用本机记录功能的前提。

03权限与分享

App 不请求设备位置、通讯录、日历、相机、麦克风或跨 App 追踪权限。通知权限为可选权限，仅在启用提醒时请求，提醒在设备上本地安排。

Excel 导出使用系统分享面板。由你决定是否保存或分享，以及分享给哪个服务或接收方。文件分享后适用所选服务的规则，开发者不会通过该导出流程接收副本。

04广告与内购

支持广告的 iOS 版本可在「今日」显示 Google AdMob 横幅。App 请求非个性化广告，并根据地区显示广告隐私选项。广告 SDK 可能处理 IP 地址、由 IP 推断的大致位置、设备标识符、广告展示和互动记录，以及崩溃和性能数据，用于投放和衡量广告、防止无效流量和诊断问题。Google 对数据的处理适用其合作伙伴网站和应用的数据使用说明。App 不会将通勤记录、费用或 iCloud 同步数据传给广告 SDK。

「永久去广告」由 Apple 处理付款。App 使用 StoreKit 验证购买权益和恢复购买。开发者不会收到你的支付卡信息。

05保存与删除

你可以修改记录，并在设置中删除通勤数据。开启同步时，删除变更会排队同步至 iCloud 及其他设备；完成同步需要网络连接和可用的 iCloud 账户。关闭同步不会删除本机或远程数据。

卸载 App 不等于删除 iCloud 数据、已导出的文件或设备备份；相关副本由你选择的保存位置及 Apple 的备份和 iCloud 设置控制。若扩展仍安装，共享容器中的数据也可能继续保留。

开发者无法承诺恢复已删除的记录。已分享的文件需在接收方单独删除。对 iCloud 私有数据库中的记录，开发者无法代替你从控制台查看或删除；请使用 App 数据控制功能及 Apple 提供的账户设置。

06支持与网站

主动发送支持邮件时，开发者及邮箱服务提供方会接收你的邮件地址、正文和附件，用于处理反馈与回复。请仅提供排查问题所必需的信息，不要发送密码，截图前遮盖不必要的私人记录。如希望删除支持邮件，可通过下方邮箱提出请求。

支持与隐私页面使用 GitHub Pages 静态托管。页面自身不加载第三方字体、统计脚本、广告或追踪像素，不设置分析 Cookie，也不提供收集通勤记录的在线表单。

网站托管与 App 本机数据是不同的处理环节。根据 GitHub 的说明，访问 GitHub Pages 时，GitHub 会为安全目的记录并存储访问者 IP 地址；其处理方式适用 GitHub 隐私声明。
